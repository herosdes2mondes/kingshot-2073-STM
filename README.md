> Help alliance members improve faster, understand events, optimize resources, and play together more efficiently.

---

# 📖 About The Project

Kingshot Guides is a lightweight static website containing strategic guides for different game systems and alliance events.

The project was created to provide:

- 📚 Easy access to important game information
- ⚔ Better alliance coordination
- 📈 Faster player progression
- 🧠 Strategic decision-making
- 🤝 A shared knowledge base for STM members
